# 序盤・引き継ぎ・復帰の回帰確認（第4PR）

このPRはテストと検証記録だけを変更する。ゲーム・Swift・能力値・画面デザインは変更しない。第3PRを前提とする。

## 実行

```sh
python3 tools/check_game_ui.py --play --animations --screenshots /tmp/ishikoro-review
```

`--play` は1戦だけの反復出撃から、`tools/check_opening_gameplay.py` の9ケースへ拡張した。既存の全標本・図鑑タブ・4画面サイズ・演出テストは残す。ゲームの計算式やセーブを変更するテスト用フラグを本体に追加していない。

テスト用サーバーが返すHTMLに、状態を読み取る関数だけを挿入する。戦闘の参考作戦は500ms間隔で有効なDOMボタンを押す。入口・仲間紹介・ステージ遷移・再開は実際のポインター入力で、重なった画面や押せないボタンを検出する。乱数は初期値713で固定し、戦闘時間はゲーム内時計を記録する。人の読む速さや楽しさ、実端末のfpsの測定ではない。

| ケース | 検証する故障 |
| --- | --- |
| 初期セーブの3戦連続 | 初回操作、報酬、次へ、古いタイマーの割り込み、再読み込みからの再開 |
| 第2戦：軽石のみ | 石を選ばなくても全て勝ててしまう変更、敗北後のおたすけが使えない変更 |
| 第2戦：前衛＋黒曜石 | 植物への相性が効かない、勝因の説明が出ない変更 |
| 第3戦：変身なし | 変身する意味が消える変更、敗北後に再挑戦できない変更 |
| 第3戦：同じ石で変身あり | 砂嵐への相性と変身の導線が壊れる変更 |
| 古い保存・引き継ぎ | 欠けた初期値、レベル・進行・6枠編成・チケット・未知の項目の喪失、無効なコードによる上書き |
| 回転・中断 | 小さい操作面、石名消失、変身中に進む時計、音の自動再開、図鑑を往復して演出を失う変更 |
| 体験版の境界 | family以外で解放制限が壊れる変更 |
| いしほり直後の移動 | 新規取得が必ず起きる既存モードで、紹介タイマーが地図へ割り込む変更 |

各戦闘でエフェクト64個以下を確認する。おたすけは、敗北から実際のボタンを押し、箱HP1875・初期マグマ270以上・堆積物9以上で再出撃できることを確認する。引き継ぎは実際のISHI1.入力欄から取り込み、直後に地図を開く。無効な入力でlocalStorageを変更していないことも比較する。

指定の一括コマンドは完了し、追加9ケースと既存の4画面サイズ・全57標本・図鑑各タブ・発見/変身/タッグ/1回と10連のいしほり演出が通過した。今回の要約は [final-regression-metrics.json](review/final-regression-metrics.json)。

結果は標準出力と `gameplay-metrics.json` に残す。失敗は非ゼロ終了し、親の `check_game_ui.py` もその終了を失敗として扱う。ゼロ件・タイムアウト・未実施を成功とはしない。テストは使い捨てのブラウザ保存だけに触れる。

## 第4・第5戦の追加観察

最初の3戦を実際にクリアした参考セーブを使い、固定乱数で続く2戦も調査した。

| 戦闘 | 参考作戦 | 結果 | ゲーム内時間 | 箱HP |
| --- | --- | --- | --- | --- |
| 第4戦 | 玄武岩を優先、黒曜石・砂岩・頁岩、変身あり | クリア | 91.7秒 | 1500 |
| 第5戦 | 砂岩と石英、変身あり | クリア | 86.2秒 | 1500 |

JavaScriptの例外は0。記録は [later-smoke-metrics.json](review/later-smoke-metrics.json)。この作戦での進行不能は確認されなかったが、全25戦や全編成を検証したものではない。

ソース上、第4→第5戦は既存の倍率が重なり、同じ通常敵のHP係数が約84%上がる。今回、4戦目以降の数値は変更していない。相性を選ぶ作戦では突破できた一方、初見プレイヤーに適切な段差かは残課題として、人のテストで特に観察する。

## PCで確認したことと、未確認のこと

- PC：Chromiumのタッチ設定で各画面・操作・戦闘・相性・変身・保存・体験版・競合を検証。WebAudioのstate、ブラウザvisibilitychange、WKWebViewから送るものと同じ中断イベントの処理を確認する。
- 未確認：Apple SDKでのSwiftビルド、iPhone/iPad実機のタッチ・読みやすさ・Safari/WKWebView・音声・ネイティブの中断復帰・低性能端末のfps・全25戦の通しプレイ。
- 人による確認：[PLAYTEST.md](PLAYTEST.md) の初見3〜5人の観察表を使う。30秒/1分/3分/10分の目標や「もう1ステージ遊びたい」は自動テストの合格から推定しない。
